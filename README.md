# O Mundo da Música

## Descrição
Este projeto apresenta uma página web sobre o mundo da música, os seus estilos e a sua importância no dia a dia.

## Objetivo
Criar uma página web utilizando HTML e CSS.

## Funcionalidades
- Apresentação da música.
- Diferentes estilos musicais.
- Importância da música.
- Menu de navegação.
  
 ## Tecnologias utilizadas 
 - HTML5
 - CSS3

   ## Como utilizar
   Abrir o ficheiro index.html num navegador.
